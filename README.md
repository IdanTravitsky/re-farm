# Resident Evil: The Farm (fan demo)

A PlayStation-style fan demo built around the farm from the 2026 film. Everything (backgrounds, models, renderer, sound) is generated from code in the source project.

Play: open `index.html` through any static web server.

Controls: arrows move (tank), Shift run, Down+Shift 180 turn, Z aim, X fire, Enter action, Tab status, Esc back.
